## 📂 Project Tracks & Deliverables Breakdown

### 📊 Task 1: Python Programming, Data Science & AI
* **Cashier Program:** A Python script managing sales with an automatic 10% discount condition applied for orders exceeding `500 EGP`.
* **Data Analysis:** An Excel sheet analyzing mall visitor traffic, determining the busiest and quietest days, supported by data visualization charts.
* **Product Classifier:** A Python Machine Learning/AI script trained to automatically sort incoming product photos into three distinct categories.

### 🌐 Task 2: HTML Web Page (Web Development)
* **Structure:** A fully responsive HTML5 page featuring a main header, introductory block, and an unnumbered list highlighting 5 distinct mall stores.
* **Styling:** Styled using CSS including custom background colors, heading typographies, and modern fonts.
* **Branding:** Displays the finalized logo generated in **Task 4**.

### 🛡️ Task 3: Protection Plan (Cyber Security)
* **Risk Assessment Matrix:** A detailed security table covering vulnerability/risk evaluations and protective countermeasures for 3 core mall networks:
  1. Free Public Wi-Fi
  2. Cashier Devices
  3. Mall Website
* **Employee Awareness:** A custom-designed infographic/sign detailing 3 simple yet crucial cybersecurity hygiene tips for mall staff.

### 🎨 Task 4: Logo & Opening Advertisement (Digital Arts)
* **Logo Design:** Includes two initial structural sketches and the finalized digital logo format.
* **Color Identity:** Selection of 3 tailored brand colors matching the "Future Mall" theme with full psychological and aesthetic explanations.
* **Marketing:** A launch advertisement banner combining the official logo, brand colors, mall name, and grand opening date.

### 🤖 Task 5: Smart Garage Gate (Embedded Systems)
* **Hardware Simulation:** Built on Wokwi using an **ESP32** microcontroller and programmed via **MicroPython**.
* **Capacity Management:** An increment/decrement button circuit tracking real-time parking spaces (Maximum threshold: 15 cars).
* **Visual Status (LEDs):**
  * 🟢 **Green:** Spaces available
  * 🔴 **Red:** Garage full
  * 🟡 **Yellow:** Car entering
  * 🔵 **Blue:** Car exiting
* **Documentation:** Includes source code, the operational Truth Table, and system circuit diagrams inside the ZIP file.
